// requirements

What you need

Operating system

Windows 10 or Windows 11, 64-bit (x64).

Disk space

About 600 MB of free space to install and run the app comfortably, plus room for the models you download (from ~0.5 GB to tens of GB).

Memory

8 GB minimum for small models; 16 GB or more for comfortable 7–8B models at Q4. GPU offload is optional.

Also useful

An internet connection to download models. Ollama is optional if you want to reuse your existing models.

WHAT'S IN 2.0.0

Release highlights

  • Built-in code editor — open a folder and edit any project in any language
  • Attach any file to a chat — code, documents, .zip and .exe (everything except audio/video)
  • Runs GGUF models locally through a bundled llama.cpp runtime
  • Ollama integration: chat with any model you have pulled
  • Built-in Hugging Face search and model downloads
  • Streaming replies, token/s readout, regeneration
  • Export conversations as Markdown or JSON
PREFER TO COMPILE IT?

Build from source

Local Chat is open source. If you would rather build it yourself, clone the repository and run the build:

git clone https://github.com/itriedcoding/local-chat
cd local-chat
npm install
npm run dist
