// requirements

What you need

Operating system

Windows 10 or Windows 11, 64-bit (x64).

Disk space

About 250 MB for the app, plus room for the models you download (from ~0.5 GB to tens of GB).

Memory

8 GB minimum for small models; 16 GB or more for comfortable 7–8B models at Q4. GPU offload is optional.

Also useful

An internet connection to download models. Ollama is optional if you want to reuse your existing models.

WHAT'S IN 1.1.0

Release highlights

  • Runs GGUF models locally through a bundled llama.cpp runtime

  • Streaming replies, token/s readout, regeneration

PREFER TO COMPILE IT?

Build from source

HackerGPT is open source. If you would rather build it yourself, clone the repository and run the build:

git clone https://github.com/itriedcoding/HackerGPT
cd HackerGPT
npm install
npm run dist
