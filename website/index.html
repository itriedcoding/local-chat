Chat, code, and build —
all on your machine.

Local Chat is a desktop app for running GGUF language models locally through llama.cpp — or connecting to the Ollama server you already use. It ships with a built-in code editor for any language and lets you attach any file to a conversation. No account. No API keys. No telemetry.

// capabilities

Everything you need to run models locally.

A real chat client — streaming, settings, exports — without a cloud account standing in the middle.

01

Run GGUF natively

Load any GGUF model straight into the app. llama.cpp powers inference on your CPU or GPU — no external runtime to install.

02

Streaming responses

Tokens appear as they are generated, with a live token-per-second readout so you know exactly how fast your hardware is running.

03

Discover models in-app

Search Hugging Face for GGUF models and download them inside Local Chat, with progress and the ability to cancel at any time.

04

Ollama, optionally

Already running Ollama? Local Chat detects the server at 127.0.0.1:11434 and lets you chat with every model you have pulled.

05

Export your chats

Save any conversation as Markdown or JSON. Copy a single reply with one click, or regenerate the last answer when you want another pass.

06

Full generation control

Set temperature, top-p, top-k, repeat penalty, max tokens and context size per chat — the same knobs the engine actually uses.

07

Built-in code editor

Open any project folder and browse, create, edit, rename and delete files from a real editor with syntax highlighting for every major language — Python, JavaScript, C/C++, Go, Rust, HTML, SQL and many more.

08

Attach any file

Drag in or pick files to give the model context: source code, documents, logs, archives (.zip), even .exe files. Everything except audio and video, which the app declines for you.

// built on open technology

Standing on the shoulders of open AI.

Local Chat is a client. The heavy lifting is done by open projects we are proud to depend on and credit.

Hugging Face

The model hub. Local Chat searches the Hugging Face API and downloads the GGUF files you choose, streaming directly to your disk.

huggingface.co ↗

Ollama

If you already run Ollama locally, Local Chat talks to its HTTP API and lists every model in your library — no extra setup.

ollama.com ↗

llama.cpp

The C/C++ inference engine that makes local LLM chat practical. Bundled into Local Chat through the node-llama-cpp bindings.

github.com/ggml-org/llama.cpp ↗
// quickstart

From download to first reply in minutes.

STEP 01

Install Local Chat

Grab the Windows installer or the portable build from the downloads page. No administrator rights are required for the portable version.

STEP 02

Get a model

Open the Discover tab to search and download a GGUF from Hugging Face, or open Models to add a local file or use an Ollama model.

STEP 03

Configure the run

Tune context size and generation settings for the way you want the model to think, then load it into memory.

STEP 04

Start chatting

Ask anything. Watch the tokens stream in, regenerate when needed, and export the conversation whenever you like.

// privacy by architecture

Your prompts stay yours.

There is no Local Chat server. Conversations, settings and models live only on your computer. The only time Local Chat touches the network is when you ask it to browse or download a model.
